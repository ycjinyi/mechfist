# MECHFIST

由 **Mech Wrangler** 制作的物理驱动机器人拳击 Demo。观看 AI 对战，或用摄像头和身体动作操控机器人，亲自迎战 AI。

A physics-driven robot boxing demo by **Mech Wrangler**. Watch AI fighters face off, or use a camera and your own body movements to control a robot against AI.

[项目官网 / Website](https://ycjinyi.github.io/mechfist/)
