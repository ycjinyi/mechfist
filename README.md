# MECHFIST

A physics-driven robot boxing demo by **Mech Wrangler**.

Watch AI-controlled robots face off, or use a single camera to control a virtual robot with your body movements and fight an AI opponent.

MECHFIST 是由 **Mech Wrangler** 制作的物理驱动机器人拳击 Demo。你可以观看 AI 自主交锋，也可以通过单个摄像头，用身体动作操控机器人，与 AI 对手对战。

## Play modes

- **AI × AI** — Watch AI-controlled robots fight, with physical interactions shaping their movements, impacts and balance.
- **YOU × AI** — Use a single camera to control a robot with your body movements against AI.

The current demo targets **Windows x86-64**. A camera is required for YOU × AI.

## Website

The showcase website is in `dist/`. Open `dist/index.html` to preview it locally. No build step is required.

Screenshots, gameplay videos and the download URL are configured in `dist/media.js`. Video files and a release download are not yet configured.

This repository contains the showcase website and release information. It does not include the game implementation.
